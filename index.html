Radxa ROCK 4D — SPI Flash

Flash edk2-rk3576 UEFI or mainline U-Boot to SPI NOR. Requires Chrome or Edge (WebUSB). No drivers needed on Linux / macOS.

  1. Hold the MaskROM button, plug in USB-C, then release
  2. Click a flash button and pick the Rockchip device from the browser prompt
  3. After the loader is sent, click Reconnect Device and pick the device again
  4. Wait for Flash complete — the board reboots automatically

Warning — read before proceeding.
This writes the selected file raw to SPI NOR starting at offset 0, overwriting the entire boot flash. An incompatible or corrupt image will make the board unbootable. Recovery requires a SPI flash programmer (e.g. CH341A) soldered directly to the flash chip. There is no undo.
